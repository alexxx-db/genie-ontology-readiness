# Pillow is an indirect dependency (xhtml2pdf -> reportlab -> Pillow). From 12.3
# Pillow publishes Linux wheels only for manylinux_2_28 (glibc >= 2.28); on an
# older container pip falls back to a source build that needs libjpeg/zlib
# headers and fails with "Failed building wheel for pillow". 12.2.0 is the last
# release with a manylinux2014 (glibc 2.17) wheel for CPython 3.11, so this cap
# keeps the install wheel-only on any runtime. Verified 2026-11-03: every other
# pin in this file resolves to a manylinux2014 wheel for CPython 3.11. Safe to
# drop once the Apps runtime is confirmed at glibc >= 2.28 (Ubuntu 22.04 is).
